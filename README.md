# Финансы

Кроссплатформенное приложение для учёта личных финансов. Работает в браузере на компьютере и телефоне и как настольная программа. Сервер не обязателен: данные хранятся на устройстве в IndexedDB, а свой сервер синхронизации делает их общими для всех устройств.

Как поставить сервер, программу на компьютер и открыть приложение на телефоне — в [INSTALL.md](INSTALL.md).

## Возможности

- **Счета** четырёх типов в разных валютах:
  - обычные;
  - сберегательные — со ставкой, оценкой процентов за месяц и целью накопления;
  - кредитные карты — с лимитом, доступным остатком, льготным периодом и процентами, которые не занимают лимит;
  - кредиты — с остатком долга, ставкой и долей погашения.
- **Операции:** доход, расход, перевод между счетами; поиск по всем месяцам и фильтр по счёту.
- **Основной счёт** (со звёздочкой) подставляется в новые операции и стоит первым в списках; без него выбирается первый по алфавиту из обычных счетов и кредитных карт.
- **Импорт выписок** из банка: CSV, Excel (.xlsx) и PDF. Столбцы находятся по заголовкам, поэтому подходят Т-Банк, Альфа-Банк и другие банки с таблицей; у PDF Сбербанка свой разбор, для остальных PDF — общий по датам и суммам. Уже записанные операции (та же сумма на этом счёте, дата ±2 дня) не задваиваются, категория подбирается по прошлым операциям с этим магазином, по категории банка и MCC, а платёж на свой счёт можно отметить переводом.
- **Взносы** по кредитам и кредитным картам: размер и дата платежа, напоминание, форма взноса с прогнозом долга, новой датой платежа и полным погашением.
- **Регулярные платежи и доходы:** подписки, аренда, зарплата. Напоминание о сроке и отметка «Оплачено» / «Получено», которая записывает операцию. Доход можно разбить на несколько выплат в месяц (аванс и основная часть).
- **Категории** доходов и расходов, у расходных — лимит на месяц.
- **Отчёт** за месяц: динамика за полгода, лимиты, кольцевая диаграмма и разбивка по категориям.
- **Резервная копия:** экспорт и импорт в файл JSON, напоминание, если копии давно не было. Импорт объединяет данные, поэтому файлом можно переносить изменения между устройствами.
- **Синхронизация:** свой сервер в домашней сети, одна база SQLite и ключ доступа; правки расходятся по устройствам сами.
- **Автокопии:** раз в день приложение само сохраняет копию данных внутри браузера и хранит две недели; к любой можно вернуться после ошибочной правки. От очистки данных браузера они не спасают — для этого нужен файл.

### Как вести долги

Долг — это отрицательный остаток счёта. Покупку по кредитной карте записывают расходом с неё, погашение карты или платёж по кредиту — переводом на этот счёт, начисленные банком проценты — расходом со счёта кредита. Переводы в отчёт о расходах не попадают, поэтому тело кредита не считается расходом дважды.

Кнопка «Внести взнос» в строке счёта делает это сама: записывает перевод, при необходимости — расход на проценты, и спрашивает дату следующего платежа.

### Льготный период

У кредитной карты задаётся дата, до которой долг гасится без процентов, и сумма, которую нужно погасить (по умолчанию весь долг). Условия у банков разные, поэтому дату приложение не вычисляет — её берут из приложения банка. Когда взнос закрывает нужную сумму, срок снимается, и форма предлагает указать следующий.

### Напоминания

О регулярном платеже, взносе по кредиту и конце льготного периода напоминают значок на вкладке, плашка на экране операций и системное уведомление (если его разрешить). Уведомления показываются, пока приложение открыто или в момент запуска: без сервера браузер не может разбудить закрытое приложение.

## Запуск

```sh
npm install
npm run dev      # режим разработки
npm test         # тесты логики
npm run test:e2e # сценарии в браузере (по умолчанию Firefox)
npm run build    # сборка в dist/
npm run preview  # просмотр сборки
npm run desktop  # настольная программа (Electron)
```


## Устройство

- `src/db.ts` — схема базы (Dexie). У каждой записи есть `id` (UUID), `updatedAt` и `deletedAt`: удаление только помечает запись. На этом построено слияние копий и будет строиться синхронизация.
- `src/money.ts` — суммы хранятся целым числом копеек.
- `src/stats.ts` — остатки счетов и месячный отчёт.
- `src/subscriptions.ts`, `src/payments.ts`, `src/notify.ts` — сроки подписок, взносы по кредитам и уведомления.
- `src/merge.ts`, `src/backup.ts` — экспорт, импорт и слияние по правилу «побеждает последняя правка».
- `src/pages/` — экраны.
- `src/sync.ts` — обмен с сервером синхронизации; `server/` — сам сервер и его установщики.
- `desktop/` — оболочка настольной программы.
- `android/` — проект приложения для Android (Capacitor); `src/native.ts`, `src/reminders.ts` — то, что на телефоне работает иначе.
- `src/statement.ts`, `src/statementFiles.ts`, `src/statementImport.ts` — разбор выписок, чтение CSV, .xlsx и PDF (pdf.js грузится только при открытии PDF), поиск дублей и подбор категорий.
- `src/snapshots.ts` — ежедневные автокопии в отдельной базе браузера.
- `e2e/` — сквозные сценарии: полный проход по приложению, импорт выписок и обновление базы первой версии. К команде можно добавить папку для скриншотов: `npm run test:e2e -- shots`. Браузер на Chromium задаётся переменной: `E2E_BROWSER=helium-browser npm run test:e2e`.
