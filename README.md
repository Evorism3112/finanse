# Финансы

Приложение для учёта кредитных карт и подписок. Полный учёт доходов и расходов оно не ведёт: покупки по карте записывать не нужно, долг просто сверяется с приложением банка. Работает в браузере на компьютере и телефоне, как настольная программа и как приложение для Android. Сервер не обязателен: данные хранятся на устройстве в IndexedDB, а свой сервер синхронизации делает их общими для всех устройств.

Как поставить сервер, программу на компьютер и открыть приложение на телефоне — в [INSTALL.md](INSTALL.md).

## Возможности

- **Сводка:** общий долг по кредиткам, сколько ещё доступно по лимитам, сколько нужно заплатить за ближайшие 30 дней и сколько уходит на подписки в месяц. Ниже — календарь ближайших платежей (обязательные платежи, концы льготных периодов, списания подписок) с кнопками «Внести» и «Оплачено» прямо в строке.
- **Кредитки:** лимит, текущий долг, доступный остаток со шкалой от зелёного к красному, обязательный платёж и его дата, день выписки, льготный период, проценты, которые входят в долг, но не занимают лимит.
  - «Обновить долг» в строке карты — вписать задолженность из приложения банка.
  - «Внести взнос» — уменьшает долг, переносит срок следующего платежа, при полном погашении снимает напоминания.
- **Подписки:** стоимость, период (неделя, месяц, год), дата списания или конца оплаченного срока, напоминание. Подписку можно привязать к кредитке — тогда «Оплачено» добавит её сумму к долгу карты.
- **Резервная копия:** экспорт и импорт в файл JSON, напоминание, если копии давно не было. Импорт объединяет данные, поэтому файлом можно переносить изменения между устройствами.
- **Синхронизация:** свой сервер в домашней сети, одна база SQLite и ключ доступа; правки расходятся по устройствам сами.
- **Автокопии:** раз в день приложение само сохраняет копию данных внутри браузера и хранит две недели; к любой можно вернуться после ошибочной правки. От очистки данных браузера они не спасают — для этого нужен файл.

### Данные прежних версий

Раньше приложение вело полный учёт: обычные счета, вклады, кредиты, операции, категории, регулярные доходы. Эти записи никуда не делись — они остаются в базе, в резервных копиях и на сервере синхронизации, но не показываются. Долг кредитки по-прежнему складывается из начального остатка и операций по ней, поэтому старые покупки и взносы учтены. Когда долг указывают вручную, поправка уходит в начальный остаток карты, история не меняется.

### Льготный период

У кредитной карты задаётся дата, до которой долг гасится без процентов, и сумма, которую нужно погасить (по умолчанию весь долг). Условия у банков разные, поэтому дату приложение не вычисляет — её берут из приложения банка. Когда взнос закрывает нужную сумму, срок снимается, и форма предлагает указать следующий.

### День выписки кредитной карты

В настройках кредитки можно указать день выписки — число месяца, когда банк рассчитывает обязательный платёж. Пока срок следующего платежа не указан, в строке карты видно «обязательный платёж рассчитают 05.11». В день выписки приложение напоминает посмотреть сумму в приложении банка, а кнопка «Указать» на сводке открывает настройки карты, чтобы её внести.

### Напоминания

О платеже по кредитке, конце льготного периода и списании подписки напоминают значок на вкладке, календарь на сводке и системное уведомление (если его разрешить). В браузере уведомления показываются, пока приложение открыто или в момент запуска; приложение для Android передаёт будущие напоминания системе.

## Запуск

```sh
npm install
npm run dev      # режим разработки
npm test         # тесты логики
npm run test:e2e # сценарии в браузере (по умолчанию Firefox)
npm run build    # сборка в dist/
npm run preview  # просмотр сборки
npm run desktop  # настольная программа (Electron)
```


## Устройство

- `src/db.ts` — схема базы (Dexie). У каждой записи есть `id` (UUID), `updatedAt` и `deletedAt`: удаление только помечает запись. На этом построены слияние копий и синхронизация.
- `src/money.ts` — суммы хранятся целым числом копеек.
- `src/cards.ts` — долг кредитки, итоги по картам, ручная правка долга, взнос и удаление карты; `src/stats.ts` — остатки и занятая часть лимита.
- `src/schedule.ts` — календарь платежей на сводке.
- `src/subscriptions.ts`, `src/payments.ts`, `src/notify.ts`, `src/reminders.ts` — сроки подписок, платежи по картам и уведомления.
- `src/merge.ts`, `src/backup.ts` — экспорт, импорт и слияние по правилу «побеждает последняя правка».
- `src/pages/` — экраны: `HomePage.tsx` — сводка, `CardsPage.tsx` и `CardForm.tsx` — кредитки, `PaymentForm.tsx` — взнос, `SubscriptionsPage.tsx` — подписки, `MorePage.tsx` — настройки.
- `src/components/Icons.tsx`, `src/colors.ts` — векторные иконки и постоянные цвета. Тема одна, тёмная; шрифт Manrope входит в сборку и работает без сети.
- `src/sync.ts` — обмен с сервером синхронизации; `server/` — сам сервер и его установщики.
- `desktop/` — оболочка настольной программы.
- `android/` — проект приложения для Android (Capacitor); `src/native.ts` — то, что на телефоне работает иначе.
- `src/snapshots.ts` — ежедневные автокопии в отдельной базе браузера.
- `e2e/` — сквозные сценарии: проход по приложению, обновление базы первой версии и синхронизация. К команде можно добавить папку для скриншотов: `npm run test:e2e -- shots`. Браузер на Chromium задаётся переменной: `E2E_BROWSER=helium-browser npm run test:e2e`.
